# Firewatch Command

Build the Flame Detector AI Dashboard based on the attached backend. It should feature a live incident feed and interactive map, fire severity classification (Local Fire <500°C, Industrial Fire 500–2000°C, Wildfire >2000°C), temperature gauges and telemetry charts, nearest fire station lookup cards with contact details, and an interactive simulation panel to trigger test sensor readings and alerts.
